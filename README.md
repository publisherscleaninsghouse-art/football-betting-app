# Football Betting App

A comprehensive football game app with real-money betting features connecting to worldwide games.

## Project Structure

```
football-betting-app/
├── backend/              # Node.js/Express backend
├── frontend/             # React web app
├── mobile/               # React Native mobile app
├── docs/                 # Documentation
├── config/               # Configuration files
└── README.md
```

## Tech Stack

- **Backend**: Node.js with Express.js
- **Frontend**: React.js
- **Mobile**: React Native
- **Database**: MongoDB
- **Real-time**: Socket.io
- **Authentication**: JWT tokens
- **Payment**: Stripe/PayPal integration

## Getting Started

1. Install Node.js (v16+)
2. Clone this repository
3. Follow setup guides in each folder
